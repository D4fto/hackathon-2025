# Meu Bairro Meu Mourão

Plataforma digital para dar voz aos moradores de Campo Mourão, facilitando o feedback sobre bairros e promovendo melhorias na cidade.

## 🚀 Sobre o Projeto

O **Meu Bairro Meu Mourão** é um espaço digital onde moradores podem compartilhar opiniões, sugestões e reclamações sobre seus bairros. A plataforma utiliza Inteligência Artificial para analisar dados e auxiliar tanto moradores quanto gestores públicos na tomada de decisões.

## ✨ Funcionalidades

- Envio de feedbacks e sugestões sobre bairros
- Chat com IA via WhatsApp para facilitar o contato
- Análise de dados e priorização de demandas para gestores
- Visualização de depoimentos de outros moradores
- Interface responsiva e fácil de usar

## 🛠️ Tecnologias Utilizadas

- ReactJS
- Vite
- CSS Modules
- Integração com WhatsApp
- Consumo de dados públicos (ex: imagens de satélite)

## 👨‍💻 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/D4fto/hackathon-2025.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse em [http://localhost:5173](http://localhost:5173)

# Meu Bairro Meu Mourão

Digital platform to give voice to the residents of Campo Mourão, making it easier to provide feedback about neighborhoods and promote improvements in the city.

## 🚀 About the Project

**Meu Bairro Meu Mourão** is a digital space where residents can share opinions, suggestions, and complaints about their neighborhoods. The platform uses Artificial Intelligence to analyze data and assist both residents and public managers in decision-making.

## ✨ Features

- Submit feedback and suggestions about neighborhoods
- AI-powered WhatsApp chat for easy communication
- Data analysis and prioritization of demands for managers
- User testimonials section
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- ReactJS
- Vite
- CSS Modules
- WhatsApp Integration
- Public data consumption (e.g., satellite images)

## 👨‍💻 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/D4fto/hackathon-2025.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Access at [http://localhost:5173](http://localhost:5173)
